# PrettyNFA

This repository is where PrettyNFA gets its updates. It holds no source code.

- **Automatic updates:** each release carries the installer and a `latest.json`. PrettyNFA reads `latest.json` to see whether a newer version is out, and only installs an update whose checksum matches.
- **Version checks:** the newest version is always the latest release on this page.
- **Update notes:** what changed in every version is listed in [CHANGELOG.md](CHANGELOG.md) and on each release.

## Download

Get the newest installer from [Releases](../../releases/latest).
